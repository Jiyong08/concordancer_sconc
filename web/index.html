1. 대괄호 자소 검색 문법 (`[초성/중성/종성]` 및 `*`, `?`, `+`)

음절을 대괄호 [ ] 안에 표기하고 초성·중성·종성을 슬래시(/)로 구분하여 검색합니다. 초·중·종성 어느 위치에나 와일드카드 문자 *, ?, +를 자유롭게 조합할 수 있습니다.

기호 / 표기 의미 및 매칭 범위 검색식 예시
[초/중/종] 초성·중성·종성이 지정한 자소와 일치하는 음절 [ㄱ/ㅏ/ㅇ] → 강
* (별표) 0개 이상의 모든 자소 허용 (종성에 쓰면 받침 유무 무관 전체 허용) [ㄱ/*/ㅇ] → 강, 공, 궁, 경, 광…
[ㄱ/ㅏ/*] → 가, 각, 간, 강, 값…
? (물음표) 임의의 자소 1개 매칭 (초·중성에 단독 ? 사용 시 모든 초·중성 허용, 합용병서 ㅅ?는 2자 병서 매칭) [?/ㅏ/ㅇ] → 강, 당, 방, 상, 장…
[ㄱ/ㅏ/?] → 홑받침(각, 간, 강…)
+ (더하기) 1개 이상의 자소가 반드시 존재해야 함 (종성에 쓰면 받침이 있는 음절만 매칭) [ㄱ/ㅏ/+] → 각, 간, 강, 값… (무받침 '가' 제외)
[초/중/] 종성 자리를 비우면 받침이 없는 음절(무받침)만 매칭 [ㅎ/ㅏ/][ㄴ/ㆍ/ㄹ] → 하ᄂᆞᆯ

3. 공백(스페이스)을 이용한 어절 경계 및 문장 첫머리 매칭 규칙

검색식 앞뒤에 스페이스(공백)를 입력하면 독립된 어절 단위로 검색을 수행할 수 있습니다.

검색식 형태 매칭 규칙 및 의미 적용 예시
' 하도 ' (앞뒤 공백) 독립된 어절로 쓰인 경우만 검색합니다.
• 앞 공백: 문장의 첫 부분(행의 첫머리)이거나 바로 앞이 공백인 경우 모두 일치합니다.
• 뒤 공백: 문장의 끝이거나 바로 뒤가 공백인 경우 일치합니다. 		매칭: 하도 세월이 좋아, 그는 하도 말이 많다
제외: 말하도록, 일하도록
' 하도' (앞 공백만) 어절의 시작 부분(어두) 또는 문장의 첫머리에 오는 경우만 검색합니다. 하도, 하더라도 (단, 말하도록은 제외)
'하도 ' (뒤 공백만) 어절의 끝 부분(어말) 또는 문장의 끝에 오는 경우만 검색합니다. 하도, 말하도 (단, 하더라도는 제외)
음절 단위 일반 검색 자소 검색 모드(jamo)를 선택하지 않은 일반 검색(all, surface)에서는 완성형 음절 단위로 검색됩니다. 하도 검색 시 받침이 붙은 하동(ㅎㅏㄷㅗㅇ) 등은 검색에서 완벽히 제외됩니다.

4. 형태소 · 형태의미(어깨번호) · 구문 표지 · 정규식 검색법

검색 방식 설명 및 문법 검색어 예시
형태소 / 품사 형태소/품사태그 또는 /품사태그 입력. 첫가끝 종성(ᆫ/ETM)과 호환자모(ㄴ/ETM)를 자동 통합 매칭합니다. 교양/NNG, ㄴ/ETM, 하/XSV
형태의미 (어깨번호) 세종 형태의미 말뭉치의 표준국어대사전 어깨번호(단어__번호 또는 단어__번호/품사)로 동음이의어를 구별 검색합니다. 세계__02, 생각__01/NNG, 일__01
구문분석 표지 세종 구문분석 트리뱅크(S-식)의 구문 표지(예: 주어 NP_SBJ, 목적어 NP_OBJ, 관형절 VP_MOD)로 검색합니다. NP_SBJ, VP_MOD, NP_OBJ
정규표현식 (Regex) 표준 정규식을 사용하여 패턴 검색을 수행합니다. 실행 시간이 길어질 경우 우측 [⏹ 검색 종료] 버튼으로 즉시 중단할 수 있습니다. [가-힣]+에서\s+[가-힣]+으로
