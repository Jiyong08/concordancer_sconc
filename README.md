# sconc (v0.1)

> **한국어 통시·공시 다층 말뭉치 통합 검색기**  
> *Korean Diachronic & Synchronic Multi-Layer Corpus Concordancer (Rust Core Engine)*

`sconc`는 현대 한국어부터 중세·근대 옛한글 문헌(언해문, 사전, 대역서)에 이르는 다양한 형식의 말뭉치를 고유 데이터베이스로 변환하고, **원문·자소·형태·형태의미·구문 주석**을 입체적으로 연동하여 초고속으로 검색·분석하는 연구용 코퍼스 검색기입니다.

---

## 🌟 주요 핵심 기능

### 1. 한컴 두벌식 옛글 입력기 및 한양 PUA ↔ 유니코드 첫가끝 통합
- **한글과컴퓨터(한컴오피스) 두벌식 옛글 오토마타** 내장:
  - `ㅏ`(`k`) 2회 연속 타건 → `ㆍ`(아래아), 3회 연속 → `ᆢ`(쌍아래아), `ㆍ` + `ㅣ` → `ㆎ`
  - `Shift+F` → `ㅿ`(반치음), `Shift+D` → `ㆁ`(옛이응), `Shift+G` → `ㆆ`(여린히읗)
  - 연서 순경음(`ㅂ+ㅇ` → `ㅸ`, `ㅁ+ㅇ` → `ㅱ`, `ㅍ+ㅇ` → `ㆄ`, `ㄹ+ㅇ` → `ᄛ`) 및 합용병서 조합
  - 마우스 클릭으로 옛글 낱자를 즉시 입력할 수 있는 화면 소형 자판 제공
- **한양 PUA(`U+E000`~`U+F8FF`) ↔ 유니코드 첫가끝(NFD)** 양방향 매핑 테이블 내장으로 어떤 옛한글 문헌이든 깨짐 없이 원문 보존 및 통합 검색 지원

### 2. 자소 검색 문법 (`[초/중/종]` 및 와일드카드)
- 음절 단위로 대괄호 `[]` 안에 초·중·종성을 `/`로 구분하여 표기:
  - `[ㄱ/ㅏ/ㅇ]` : '강' 음절 매칭
  - `[ㄱ/*/ㅇ]산` : 초성 ㄱ, 종성 ㅇ 사이 임의 모음(0개 이상 자소) + '산' (강산, 공산, 경산 등)
  - `[?/ㅏ/ㅇ]산` : 임의의 1개 초성 자모 + ㅏ + 종성 ㅇ + '산'
  - `[ㅅ/ㅏ/][ㄹ/ㆍ/+]` : `+`를 종성에 사용하여 받침이 반드시 존재하는 음절만 한정 매칭 (옛한글 '사ᄅᆞᆷ' 등)

### 3. 다층 주석 연동 및 상세 뷰어 (원문 · 형태 · 형태의미 · 구문)
- 동일한 원문 문장에 연결된 형태소 분석, 형태의미(어깨번호 예: `세계__02`), 구문 분석 트리(S-Expression Tree)를 단일 레코드로 입체 결합
- KWIC 검색 결과 행을 클릭하면 접이식(Folding) 상세 뷰어에서 어절별 카드, 구문 트리, 출전 정보 및 전후 문맥을 확인 가능
- 연구 중 발견한 오류를 화면에서 직접 수정하는 실시간 DB 수정 기능 지원

### 4. 문맥 절단 방지 (Cross-Segment KWIC Padding)
- 검색어가 문장의 시작이나 끝에 있어 현재 문장 내 어절 수가 부족하더라도, 동일 문서의 직전·직후 문장에서 어절을 자동 연결하여 **좌우 5어절(또는 지정 어절 수)** 문맥을 끊김 없이 자연스럽게 표시

### 5. 다중 탭 검색 및 결과 비교 (최대 10개 탭)
- 새 검색식을 입력할 때마다 검색어 이름의 새 탭이 생성되어 기존 검색 결과를 유지
- 최대 10개 탭을 자유롭게 오가며 서로 다른 어휘나 형태소의 검색 결과·용례를 나란히 비교 대조

### 6. 결과 내 재검색 (Sub-search / 필터) & 텍스트 저장 (Export)
- 수천 건의 검색 결과 내에서 특정 어휘, 품사, 문서명 등으로 즉시 2차 필터링
- **[💾 결과 TXT 저장]** 버튼을 통해 표시된 용례 결과를 UTF-8 BOM 탭 구분 텍스트(TSV)로 로컬 다운로드 (엑셀/메모장 한글 깨짐 방지)

### 7. 마우스 우클릭 원문 텍스트 점프 (Source Jump Viewer)
- KWIC 용례 행에서 마우스 우클릭 후 `[📄 원본 파일에서 이 문장 위치 보기]`를 누르면, 원본 파일의 실제 행 번호와 전후 30줄의 원시 텍스트(태그/마크업 포함)를 모달 뷰어에서 대상 줄 하이라이트와 함께 확인

### 8. 폴더 지정 말뭉치 DB 자동 변환기 (`corpus_builder.py`)
- 사용자가 원본 파일들이 들어 있는 폴더 경로만 지정하면, 파일 형식과 인코딩(`UTF-8`, `UTF-16LE/BE`, `CP949`)을 자동 판별하여 통합 DB(`.corpdb`)를 생성:
  - 세종 3중 연동 말뭉치 (`BTAA` 형태 + `BSAA` 의미 + `BGAA` 구문)
  - 역사 언해문/대역서/외국어학습서 (`간이벽온방`, `첩해신어` 등)
  - 옛한글 사전/자석류 (`훈몽자회` 등)
  - 한국어 학습자 말뭉치 (`.txt` + `.xml`)
  - 모두의 말뭉치 JSON (형태 분석 및 원시 문단)
  - 세종 TEI 텍스트 (문어 `2BA*`, 구어 전사 `4CM*`, 구어 형태소 `5CT*`)
  - 일반 평문 텍스트 및 대본/희곡 (`.txt`)

### 9. 8GB RAM 저사양 PC 최적화 & 적응형 메모리 프로파일
- 최소 8GB RAM PC에서도 메모리 150~300MB 수준으로 쾌적하게 동작
- 고사양 PC(16GB / 32GB / 64GB+)에서는 시스템 가용 RAM을 자동 감지하여 SQLite 메모리 매핑(`mmap`)과 인메모리 캐시를 자동 확장

## 🚀 빠른 시작 (Quick Start)

### 시스템 요구사항
- **운영체제**: Windows 10/11 (64-bit), macOS, Linux
- **메모리**: 최소 4GB~8GB RAM (16GB+ 권장)
- **필수 도구**: [Rust](https://rustup.rs/) (Cargo), [Python 3.8+](https://www.python.org/)

---

### Windows 설치 및 전역 실행 설정

1. **저장소 클론**:
   ```bash
   git clone https://github.com/Jiyong08/concordancer_sconc.git
   cd concordancer_sconc
   ```

2. **자동 환경 설치기 실행**:
   `install.bat`을 더블클릭하거나 터미널에서 실행합니다:
   ```cmd
   install.bat
   ```
   - Python 및 Rust 설치 여부를 자동 점검합니다.
   - 고속 릴리스 엔진(`engine/target/release/sconc.exe`)을 빌드합니다.
   - `%USERPROFILE%\.cargo\bin\sconc.cmd`를 등록하여, **컴퓨터 어느 폴더에서든 터미널에 `sconc`를 입력하면 바로 실행**될 수 있도록 설정합니다.

3. **프로그램 실행**:
   - `run_sconc.bat`을 더블클릭하거나,
   - 명령 프롬프트(CMD) 또는 PowerShell 어디에서든 아래 명령어를 입력합니다:
     ```cmd
     sconc
     ```
   - 기본 브라우저가 자동으로 열리며 검색 화면(`http://localhost:8787`)이 표시됩니다.

---

### macOS / Linux 설치

```bash
chmod +x install.sh
./install.sh
sconc
```

## 📖 말뭉치 데이터베이스 구축 방법

`sconc`는 데이터베이스가 비어 있어도 프로그램이 정상 기동되며, 웹 화면 또는 명령줄에서 손쉽게 데이터베이스를 생성할 수 있습니다.

### 방법 1: 웹 화면에서 생성 (권장)
1. 상단 내비게이션의 **[📁 말뭉치 폴더 지정 DB 생성]** 탭을 클릭합니다.
2. 원본 말뭉치 파일들이 위치한 폴더 경로를 입력합니다. (예: `D:\Corpus\sample`)
3. **[🚀 데이터베이스 생성 시작]** 버튼을 클릭합니다.
4. 파일 형식 자동 감지 및 변환이 완료되면 분석 보고서가 출력되며, **[🔍 생성된 데이터베이스로 검색하기]** 버튼을 눌러 즉시 검색할 수 있습니다.

### 방법 2: 명령줄(CLI)에서 생성
```bash
python corpus_builder.py --folder "원본말뭉치폴더경로" --db "db/concordance.corpdb"
```
