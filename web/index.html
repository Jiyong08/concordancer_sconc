1. 검색 단위(어절·문장·텍스트) 및 검색 대상 층위(단일 선택) 안내

상단 [검색단위] 메뉴에서 검색어가 적용되는 범위를 지정하고, 우측 [📌 기본값] 버튼으로 원하는 기본 검색 단위를 저장할 수 있습니다. 또한 [검색방식] → [1. 검색 대상 층위]에서는 4개 층위 중 하나를 선택하여 해당 분석 말뭉치에서만 정밀 검색합니다.

검색 단위 검색어 적용 범위 및 어절 시작 매칭 규칙 하[ㄴ/1/01].{1,10}/NNG 예시
어절 단위 검색 어절 시작부분부터 매칭하며, 단일 어절 내부에서만 검색합니다. 어절 중간에 나타나는 형태소(예: 자제하는의 하)는 제외됩니다. 하늘이[하늘/NNG+이/JKS], 하나님과[하나님/NNG+과/JKB] 매칭 (자제하는 제외)
문장 단위 검색 어절 시작부분부터 매칭하되, 어절 경계를 넘어서 한 문장 경계 안에서 검색합니다. 하는[하/VV+는/ETM] 일을[일/NNG+을/JKO] 매칭 (자제하는 제외)
텍스트 단위 검색 어절 시작 제한이나 어절·문장 경계 없이 텍스트 전체(인접 문장 경계 포함)에서 자유롭게 검색합니다. 어절 내부·어절 간·문장 간 경계 없이 모든 일치 구간 검색
검색 대상 층위 (택1) 설명 및 전용 말뭉치 필터링 검색어 예시
원문 표층 원문 본문 및 옛한글 표층 텍스트에서 검색합니다. 하ᄂᆞᆯ, [ㄱ/ㅏ/01]
형태소 / 품사 형태소 분석 말뭉치에서만 검색하며, KWIC 화면에 형태분석 결과를 함께 표시합니다. (ᆫ/ETM·ㄴ/ETM 자동 통합) 하[ㄴ/1/01].{1,10}/NNG, 교양/NNG, ㄴ/ETM
형태의미 형태의미 분석 말뭉치에서만 어깨번호(단어__번호)를 검색하고 결과를 표시합니다. 세계__02, 생각__01/NNG
구문표지 구문분석 말뭉치에서만 S-식 구문 태그를 검색하고 구문 트리를 표시합니다. NP_SBJ, VP_MOD, NP_OBJ

2. 대괄호 자소 검색 문법 (`0`, `1`, `01` 슬롯 표기법 및 정규식 결합)

한글 음절을 대괄호 [초성/중성/종성] 안에 슬래시(/)로 구분하여 검색합니다.
자소 자리마다 0(없음/0개), 1(임의의 1개 자소), 01(0개 또는 1개)을 입력하여 정밀하게 검색할 수 있습니다.

기호 / 표기 의미 및 매칭 규칙 검색식 예시 및 설명
0 (0개) 해당 자리에 자소가 0개(없음)인 경우 매칭 (종성에 쓰면 받침 없는 음절) [ㄱ/ㅏ/0] → 가 ('각, 간' 제외)
[1/1/0] → 받침 없는 모든 음절
1 (1개) 해당 자리에 자소가 임의의 1개 존재하는 경우 매칭 (종성에 쓰면 받침 있는 음절) [ㄱ/ㅏ/1] → 각, 간, 갇, 갈, 닭…
[1/ㅏ/0] → 가, 나, 다, 라… (무받침 'ㅏ' 음절)
[1/1/1] → 받침 있는 모든 음절
01 (0개 또는 1개) 해당 자리에 자소가 있거나 없거나(0개 또는 1개) 모두 검색 [ㄱ/ㅏ/01] → 가, 각, 간, 갈… ('가' 계열 전체)
[ㅎ/ㅏ/0][ㄴ/ㆍ/01] → 하ᄂᆞ, 하ᄂᆞᆯ
형태소 자소 검색 형태소/품사 층위에서도 자소 패턴으로 어근·어간 매칭 가능 [1/ㅏ/0]/VV → 가/VV, 사/VV, 차/VV…
자소 + 정규식 복합 자소 검색과 정규표현식을 동시 체크하여 복합 패턴 검색 가능 [ㄱ/ㅏ/0].*다/EF → '가'로 시작해 종결어미 '다'로 끝나는 구문
