# 한국어 말뭉치 통합 검색기 S-conc v0.2

> **한국어 통시·공시 다층 말뭉치 통합 검색기 (무설치 독립 실행형 데스크톱 애플리케이션)**  
> *Korean Diachronic & Synchronic Multi-Layer Corpus Concordancer (Standalone Zero-Install Desktop App)*

`S-conc`는 현대 한국어부터 중세·근대 옛한글 문헌(언해문, 사전, 대역서) 및 대규모 학습자 말뭉치에 이르는 다양한 형식의 텍스트를 고성능 코퍼스 데이터베이스로 변환하고, **원문 표층·자소·형태소·형태의미·구문 주석**을 입체적으로 연동하여 초고속으로 검색·분석하는 전문 코퍼스 분석 도구입니다.

- **외부 설치 불필요 (Zero-Install)**: Python, Rust, Node.js 등 어떤 런타임도 설치할 필요 없이 **`sconc.exe` 실행 파일 하나만 더블클릭**하면 즉시 구동됩니다.
- **순수 네이티브 독립 창**: 로컬 웹서버나 외부 브라우저(Chrome/Edge 등)를 띄우지 않고, Windows 내장 WebView2를 품은 독립 데스크톱 창으로 작동하여 방화벽·프록시 제약이 없으며 창을 닫으면 백그라운드 잔류 없이 100% 완전 종료됩니다.

---

## 🚀 빠른 시작 (Quick Start)

1. 배포 폴더에서 **`sconc.exe`** (또는 `run_sconc.bat`)를 더블클릭합니다.
2. 별도의 설정이나 설치 과정 없이 즉시 독립 데스크톱 애플리케이션 창이 실행됩니다.

---

## 📖 프로그램 사용법 가이드

`S-conc`는 상단 내비게이션 탭을 통해 말뭉치 구축부터 검색, 분석까지 직관적인 작업 흐름을 제공합니다:

```
[⚙️ 말뭉치 폴더 지정 DB 생성]  ➜  [📁 구축데이터베이스 문서 목록]  ➜  [🔍 다층 말뭉치 통합 검색]
```

### Step 1. 말뭉치 데이터베이스(DB) 구축 방법

자신이 보유한 원문 텍스트나 말뭉치 파일들을 검색 가능한 데이터베이스(`.corpdb`)로 변환합니다.

1. 상단 세 번째 탭인 **`[⚙️ 말뭉치 폴더 지정 DB 생성]`**을 클릭합니다.
2. **`[📂 폴더/파일 찾아보기...]`** 버튼을 누릅니다.
   - 탐색기 창이 처음 열릴 때는 `C:\` 드라이브가 열리며, 이후에는 **사용자가 마지막으로 열었던 폴더 경로를 기억**하여 해당 위치가 바로 열립니다.
   - **폴더 선택**: 특정 폴더를 선택하면 해당 폴더 및 **모든 하위 폴더 내의 말뭉치 파일들을 재귀적으로 자동 탐색**합니다.
   - **단일 / 복수 파일 선택**: 폴더 전체가 아닌 특정 파일 하나 또는 `Ctrl`/`Shift` 키를 이용해 **여러 개의 파일을 동시에 선택**하여 DB에 추가할 수도 있습니다.
3. **`생성/저장할 DB 파일명`**을 지정합니다. (기본값: `concordance.corpdb` — 다른 이름을 입력하여 주제별·문헌별 모듈형 DB 구축 가능)
4. **`[🚀 데이터베이스 생성 시작]`** 버튼을 누르면 고속 변환 프로세스가 시작됩니다.

> ⏳ **처음 DB 구축 시 안내사항**  
> 처음 데이터베이스를 구축할 때는 대용량 텍스트의 문장·어절 분절, 형태소·구문 분석 태그 파싱, 초·중·종성 자소 인덱싱, 화자 및 서지 메타데이터 분류 추출 작업을 종합적으로 수행합니다. 따라서 **처리할 텍스트 파일의 용량과 개수에 따라 초기 구축에 다소 시간이 소요될 수 있습니다.**  
> 화면 중앙의 진척도 카드와 상단 실시간 진행률(`%`) 배지를 통해 현재 처리 중인 파일명과 진행 상황을 실시간으로 확인할 수 있습니다.

- **지원 포맷 및 인코딩 자동 감지**:
  - 한국어 학습자 말뭉치(`<Korean_Learners_Corpus>` XML — `<Header>` 화자/환경 메타데이터 분리, `<P>`/`<word>` 원문 복원, `<morph pos="...">` 21세기 세종계획식 변환)
  - 21세기 세종계획 문어 원시 말뭉치(TEI SGML/XML), 형태분석, 형태의미분석(어깨번호), 구문분석 말뭉치(단독 및 3중 연동)
  - 국립국어원 모두의 말뭉치(JSON), 옛한글 언해문 및 사전 자료, 일반 평문 텍스트(`.txt`, `.csv`, `.tsv`)
  - `UTF-8`, `UTF-8-SIG`, `UTF-16LE`, `UTF-16BE`, Windows 한국어 `CP949` 인코딩 자동 감지 및 변환

### Step 2. 구축된 DB 선택 및 문서 목록 확인

1. 상단 두 번째 탭인 **`[📁 구축데이터베이스 문서 목록]`**을 클릭합니다.
2. 현재 구축된 데이터베이스 파일(`.corpdb`) 목록을 확인하고 원하는 DB를 선택합니다.
3. 문서 목록 테이블에는 각 말뭉치의 기본 정보(문서 ID, 제목, 문장 수, 어절 수)와 함께 말뭉치 파일에서 추출된 메타데이터가 체계적으로 표시됩니다:
   - **화자 정보**: 학습자/화자의 연령, 국적, 성별, 모어, 숙달도 등급, 직업 등
   - **기타 정보**: 문헌 장르, 주제, 작성 매체, 과제 유형, 출처, 작성 일자 등
   - **요약 및 상세 확인**: 창 크기에 맞추어 깔끔하게 축약(`...`) 표시되며, 마우스를 올리면 **툴팁**으로 전체 내용이 나타납니다. 해당 셀을 클릭하면 **상세 모달 팝업**이 열려 모든 메타데이터를 태그별로 한눈에 확인할 수 있습니다.

### Step 3. 사용자말뭉치(말뭉치 묶음) 선택 및 관리

관심 있는 특정 문서들만 묶어서 집중적으로 검색하고자 할 때 유용한 기능입니다.

1. **`[📁 구축데이터베이스 문서 목록]`**에서 원하는 문서들의 좌측 체크박스를 선택합니다.
   - `Shift` 키를 누른 채 체크박스를 클릭하면 여러 행을 한 번에 연속 범위 선택할 수 있습니다.
2. 상단 버튼 중 **`[📚 선택한 말뭉치 → 사용자말뭉치 저장]`**을 클릭합니다.
3. 팝업창에서 원하는 묶음 이름(예: `초급_중국인_학습자`, `훈민정음_언해류` 등)을 입력하고 저장합니다.
4. 검색 탭의 상단 검색 옵션 바에서 **`[문서지정]`** 버튼을 클릭하면, 저장해 둔 `사용자말뭉치` 묶음을 원클릭으로 선택하여 **해당 묶음에 속한 말뭉치들만 대상으로 초고속 검색**을 수행할 수 있습니다.
   - 문서 목록에서 체크 후 **`[🔍 선택한 말뭉치에서 검색]`** 버튼을 누르면 검색 화면으로 즉시 전환되며 해당 문서들만 선택된 상태로 검색이 시작됩니다.

### Step 4. 검색 단위 및 검색 대상 층위 선택

검색어 입력창 위의 옵션 바에서 검색 단위와 대상 층위를 설정합니다.

#### 1) 3단계 검색 단위 (어절 / 문장 / 텍스트)
- **어절 단위 검색 (기본 권장)**: 각 어절의 **시작부분**부터 매칭하며, **단일 어절 경계 안에서만** 검색합니다.
  - 예: `하[ㄴ/1/01].{1,10}/NNG` 검색 시 `'자제하는'`(`자제/NNG+하/XSV+는/ETM`)처럼 어절 중간에 `'하'`가 들어간 어절을 배제하고, 어절이 `'하'`로 시작하는 명사 어절(`하늘이[하늘/NNG+이/JKS]`, `하나님과[하나님/NNG+과/JKB]` 등)만 정확히 추출합니다. (어절 중간부터 찾으려면 앞에 `.*` 추가)
- **문장 단위 검색**: 어절 시작부분부터 매칭하되, **어절 경계를 넘어 한 문장 경계 안에서** 검색합니다.
- **텍스트 단위 검색**: 어절 시작 제한이나 문장 경계 없이 **인접 문장을 넘나들며 텍스트 전체에서 자유롭게** 검색합니다.
- **`[📌 기본값]` 버튼**: 사용자가 선호하는 검색 단위를 기본값으로 영구 저장합니다.

#### 2) 검색 대상 층위 (단일 선택 - 택 1)
- **원문 표층**: 원문 텍스트 및 옛한글 표층 형태에서 검색합니다.
- **형태소 / 품사**: **형태소 분석 정보가 있는 말뭉치에서만 검색**하며, KWIC 결과 행 및 하단 주석 줄에 형태소 분석 결과(`어절[형태소/품사+...]`)를 함께 출력합니다. (옛이응 `ᅌ`/`ㆁ`, 관형사형 전성어미 `ᆫ/ETM`과 `ㄴ/ETM` 등 자모 변이형 자동 통합 매칭)
- **형태의미**: **형태의미 분석 말뭉치에서만 검색**하며, 동형이의어 어깨번호(예: `세계__02`, `생각__01/NNG`)를 식별하여 검색합니다.
- **구문표지**: **구문분석 말뭉치에서만 검색**하며, 구문 트리 표지(예: `NP_SBJ`, `VP_MOD`, `NP_OBJ` 등)를 검색하고 S-Expression 구문 분석 트리를 표시합니다.

### Step 5. 검색 연산 방식 (정규식, 자소 검색)

상단 `[검색방식]` 팝업에서 연산 방식을 조합할 수 있습니다.

1. **단순 텍스트 검색**: 입력한 문자열 그대로 정확히 일치하는 용례 검색
2. **정밀 자소 검색 (`[초/중/종]` 및 `0`, `1`, `01` 규칙)**:
   - 한글 음절을 대괄호 `[초성/중성/종성]` 슬롯으로 나누어 정밀 검색:
     - `0` (없음): 해당 자리에 자소가 **0개(없음)** (종성에 쓰면 **받침 없는 음절**)
       - `[ㄱ/ㅏ/0]` → **가**만 매칭 ('각, 간' 등 받침 있는 음절 제외)
       - `[1/1/0]` → 받침 없는 모든 음절 매칭
     - `1` (1개 존재): 해당 자리에 자소가 **임의의 1개 존재** (종성에 쓰면 **받침 있는 음절**)
       - `[ㄱ/ㅏ/1]` → **각, 간, 갇, 갈, 닭…** 매칭
       - `[1/ㅏ/0]` → 받침 없는 '가, 나, 다, 라…' 매칭
       - `[1/1/1]` → 받침 있는 모든 음절 매칭
     - `01` (0개 또는 1개): 해당 자리에 자소가 **있거나 없거나 모두 매칭**
       - `[ㄱ/ㅏ/01]` → **가, 각, 간, 갈…** 모두 매칭
       - `[ㅎ/ㅏ/0][ㄴ/ㆍ/ㄹ]` → 옛한글 **'하ᄂᆞᆯ'** 정밀 자소 매칭
3. **정규식(Regex) 검색**: `.{1,5}`, `|`, `+`, `?`, `^`, `$` 등 정규 표현식 메타문자를 사용한 자유 패턴 검색
4. **자소 + 정규식 복합 검색**: 자소 슬롯 표기와 정규식을 결합하여 고난도 언어학적 패턴 질의
   - 예: `하[ㄴ/1/01].{1,10}/NNG` (어절 시작이 '하'이며 받침이 있거나 없는 'ㄴ' 계열 음절로 이어지는 명사)

### Step 6. 현대한글 및 한컴 두벌식 옛글 입력 방식

검색어 입력창 우측의 **`옛한글 입력 [ON/OFF]`** 스위치로 입력 모드를 전환할 수 있습니다.

- **한컴 두벌식 옛글 오토마타 조작법**:
  - `ㅏ`(`k`) 연속 타건: `ㅏ` → `ㆍ`(아래아) → `ᆢ`(쌍아래아), `ㆍ` + `ㅣ` → `ㆎ`
  - 특수 자모 단축키:
    - `Shift + A` 또는 `Shift + F` → `ㅿ` (반치음)
    - `Shift + S` 또는 `Shift + D` → `ㆁ` (옛이응)
    - `Shift + G` → `ㆆ` (여린히읗)
  - 순경음 연서 조합: `ㅂ + ㅇ` → `ㅸ`, `ㅁ + ㅇ` → `ㅱ`, `ㅍ + ㅇ` → `ㆄ`, `ㄹ + ㅇ` → `ᄛ`
  - 합용병서 조합: `ㅂ + ㅅ` → `ᄡ`, `ㅂ + ㄷ` → `ᄠ`, `ㅂ + ㅅ + ㄱ` → `ᄣ` 등 자유로운 복합 자음 입력
- **입력 편의성**: 옛한글 입력 모드(ON) 중에도 대괄호 자소 표기(`[초/중/종]`), 정규식 기호, 숫자, 영문, 문장부호는 오토마타의 방해 없이 자유롭게 타이핑할 수 있습니다.
- **한양 PUA ↔ 유니코드 첫가끝(NFD) 자동 정규화**:
  - 고문헌 원문에 옛한글이 한양 PUA 코드(`U+E000`~`U+F8FF`)로 저장되어 있더라도, 검색창에 표준 유니코드 첫가끝 자모로 입력하면 엔진이 양방향 자동 정규화하여 누락 없이 매칭합니다.
- **클릭형 소형 옛글 낱자판**: 키보드 입력 외에도 `[⌨️ 옛글 낱자판]` 버튼을 누르면 화면에 나타나는 가상 낱자판을 클릭하여 원하는 옛글 자모를 손쉽게 입력할 수 있습니다.

### Step 7. 기타 프로그램 활용 기능

1. **`💾 결과 TXT 저장`**:
   - 검색 결과 상단의 저장 버튼을 누르면 Windows 파일 저장 대화상자가 열려 **저장 위치와 파일명을 사용자가 직접 지정**하여 UTF-8 BOM TSV 텍스트 파일(`.txt`)로 내보낼 수 있습니다.
2. **`📄 원문으로의 점프` (Source Jump)**:
   - 검색 결과(KWIC) 행에서 마우스 우클릭 후 `[📄 원문으로의 점프]`를 선택하면, 원본 텍스트 파일의 해당 문장이 위치한 **정확한 행(Line) 번호로 즉시 점프**하여 전후 원문 맥락을 검토할 수 있으며, PC 기본 텍스트 에디터(VS Code, Notepad++, 메모장 등)로 즉시 열어볼 수 있습니다.
3. **문맥 절단 방지 (Cross-Segment KWIC Padding)**:
   - 검색어가 문장의 시작이나 끝에 위치하더라도, 동일 문서의 직전·직후 문장에서 어절을 자동 연결하여 **좌우 5어절(또는 지정 어절 수) 문맥을 끊김 없이 자연스럽게 표시**합니다.
4. **다중 탭 검색 (최대 10개) 및 결과 내 재검색**:
   - 최대 10개의 독립적인 검색 탭을 띄워 서로 다른 검색어 결과를 비교 분석할 수 있으며, 검색 결과 내에서 추가 검색어로 필터링하는 2차 재검색을 지원합니다.
5. **화면 최적화 기능**:
   - 상단 우측 화면비율 셀렉터: `모니터 맞춤(자동)`, `16:9 와이드`, `4:3 표준`, `창 전체 채우기`
   - 검색창 우측 `[🔼 검색 옵션 접기]` 버튼: 상단 헤더와 검색 옵션 바를 한 번에 접어 검색 결과 목록을 화면 가득 확장
