# sconc (v0.1)

> **한국어 통시·공시 다층 말뭉치 통합 검색기 (무설치 독립 실행형 애플리케이션)**  
> *Korean Diachronic & Synchronic Multi-Layer Corpus Concordancer (Standalone Zero-Install Rust Engine)*

`sconc`는 현대 한국어부터 중세·근대 옛한글 문헌(언해문, 사전, 대역서)에 이르는 다양한 형식의 말뭉치를 고유 데이터베이스로 변환하고, **원문·자소·형태·형태의미·구문 주석**을 입체적으로 연동하여 초고속으로 검색·분석하는 연구용 코퍼스 검색기입니다.

---

## 🌟 주요 핵심 기능

### 1. 무설치 단독 실행 (`sconc.exe`) & 공용 네트워크 완벽 호환
- **외부 라이브러리·런타임 무설치(Zero-Install)**: Python, Rust, Node.js 등을 별도로 설치할 필요 없이 **`sconc.exe` 실행 파일 하나만 더블클릭**하면 즉시 구동됩니다.
- **내장 Rust 말뭉치 DB 빌더**: 외부 스크립트 없이 `sconc.exe` 자체 내장 엔진(`engine/src/builder.rs`)만으로 11종의 말뭉치 포맷과 인코딩(`UTF-8`, `UTF-16LE/BE`, `CP949`)을 자동 감지하여 실시간 진행률(`%`)과 함께 고속 DB화를 수행합니다.
- **독립 앱 창 모드(App Mode) & 프록시 우회**: 공용 네트워크(대학·기관·공공 와이파이 등)에서도 방화벽이나 프록시 차단 없이 `127.0.0.1` 루프백과 `--app` 독립 데스크톱 창 모드로 즉시 열립니다.

### 2. 한컴 두벌식 옛글 입력기 및 한양 PUA ↔ 유니코드 첫가끝 통합
- **한글과컴퓨터(한컴오피스) 두벌식 옛글 오토마타** 내장:
  - `ㅏ`(`k`) 2회 연속 타건 → `ㆍ`(아래아), 3회 연속 → `ᆢ`(쌍아래아), `ㆍ` + `ㅣ` → `ㆎ`
  - `Shift+A`(`ㅁ`) 또는 `Shift+F` → `ㅿ`(반치음), `Shift+S`/`Shift+D` → `ㆁ`(옛이응), `Shift+G` → `ㆆ`(여린히읗)
  - 연서 순경음(`ㅂ+ㅇ` → `ㅸ`, `ㅁ+ㅇ` → `ㅱ`, `ㅍ+ㅇ` → `ㆄ`, `ㄹ+ㅇ` → `ᄛ`) 및 합용병서 조합
  - 옛한글 입력(ON) 상태에서도 대괄호 자소 검색(`[초/중/종]`), 정규식 메타문자, 숫자·영문·문장부호를 모드 전환 없이 자유롭게 입력 가능
- **한양 PUA(`U+E000`~`U+F8FF`) ↔ 유니코드 첫가끝(NFD)** 양방향 매핑 테이블 내장

### 3. 정밀 자소 검색 문법 (`[초/중/종]` 및 `0`, `1`, `01` 규칙)
- 음절 단위로 대괄호 `[]` 안에 초·중·종성을 `/`로 구분하여 표기:
  - `0` : 해당 자리에 자소가 **없음(0개)** (예: `[ㄱ/ㅏ/0]` → 받침 없는 '가'만 매칭)
  - `1` : 해당 자리에 임의의 자소가 **1개 존재** (예: `[1/ㅏ/0]` → 받침 없는 '가, 나, 다, 라…' 모두 매칭, `[ㄱ/ㅏ/1]` → 받침 있는 '각, 간, 갈…' 매칭)
  - `01` : 해당 자리에 자소가 **있거나 없거나(0개 또는 1개) 모두 매칭** (예: `[ㄱ/ㅏ/01]` → '가, 각, 간…' 모두 매칭)
  - `[ㅎ/ㅏ/0][ㄴ/ㆍ/ㄹ]` : 옛한글 '하ᄂᆞᆯ' 정밀 자소 매칭

### 4. 3단계 검색단위(`어절` / `문장` / `텍스트`) 및 어절 시작부분 정밀 매칭
- 상단 **`문서지정`** 버튼 옆의 **`검색단위`** 메뉴에서 검색어가 적용되는 범위를 3단계로 선택할 수 있으며, **`📌 기본값`** 버튼으로 사용자가 선호하는 디폴트 검색단위를 저장할 수 있습니다:
  - **어절 단위 검색**: 각 어절의 **시작부분**부터 매칭하며, **한 어절 경계 안에서만** 검색합니다. 예를 들어 `하[ㄴ/1/01].{1,10}/NNG` 검색 시 `'자제하는'`(`자제/NNG+하/XSV+는/ETM`)처럼 어절 중간에 `'하'`가 들어간 어절이나 어절 경계를 넘어선 매칭을 배제하고, 어절이 `'하'`로 시작하는 명사 어절(`하늘이[하늘/NNG+이/JKS]`, `하나님과[하나님/NNG+과/JKB]` 등)만 정확히 찾아냅니다. (어절 중간부터 매칭하려면 앞에 `.*`를 붙입니다.)
  - **문장 단위 검색**: 어절 시작부분부터 매칭하되, **어절 경계를 넘어서 한 문장 경계 안에서** 검색합니다.
  - **텍스트 단위 검색**: 어절 시작이나 문장 경계 제한 없이 **어절 내부 임의 위치 및 인접 문장 경계를 넘어서** 자유롭게 검색합니다.

### 5. 단일 선택 검색 대상 층위 & 다층 주석 말뭉치 전용 검색·표시
- **`검색 방식` → `1. 검색 대상 층위`**에서 **`원문 표층`**, **`형태소/품사`**, **`형태의미`**, **`구문표지`** 4가지 중 **하나만 선택(단일 선택)**하여 검색 층위를 명확히 지정할 수 있습니다.
- **`형태소/품사`**를 선택하면 **형태소 분석 말뭉치에서만** 검색이 이루어지며, 검색 결과 화면(KWIC 행 및 하단 주석 줄)에 매칭된 형태소 분석 정보(`어절[형태소/품사+...]`)가 함께 출력됩니다. (**`형태의미`**, **`구문표지`** 선택 시에도 각각 해당 주석 말뭉치에서만 검색 및 표시)
- 동일한 원문 문장에 연결된 형태소 분석, 형태의미(어깨번호 예: `세계__02`), 구문 분석 트리(S-Expression Tree)를 단일 레코드로 입체 결합합니다.
- **말뭉치 선택 삭제 및 재구축**: 구축 데이터베이스 문서 목록에서 체크박스(Shift 키 연속 범위 선택 지원)로 특정 말뭉치를 선택하여 삭제하고, 언제든 원문 코퍼스로부터 다시 DB를 구축할 수 있습니다.

### 6. 문맥 절단 방지 (Cross-Segment KWIC Padding) & 실시간 스트리밍 검색
- 검색어가 문장의 시작이나 끝에 있어 현재 문장 내 어절 수가 부족하더라도, 동일 문서의 직전·직후 문장에서 어절을 자동 연결하여 **좌우 5어절(또는 지정 어절 수)** 문맥을 끊김 없이 자연스럽게 표시
- 대용량 말뭉치 검색 시 매칭되는 문장을 발견 즉시 실시간 스트리밍으로 화면에 출력

### 7. 다중 탭 검색(최대 10개) · 결과 내 재검색 · 원문 에디터 점프
- 최대 10개 검색 탭을 오가며 용례 비교, 결과 내 재검색(2차 필터), UTF-8 BOM TSV 텍스트 저장 지원
- KWIC 용례 행에서 마우스 우클릭 시 원본 텍스트 파일의 해당 행 번호로 즉시 점프 및 PC 기본 텍스트 에디터(VS Code, Notepad++, 메모장 등)로 열기 지원

## 🚀 빠른 시작 (Quick Start — 무설치 독립 실행)

### 방법 A: Windows 무설치 즉시 실행 (권장)
1. 이 저장소를 다운로드(`Code` → `Download ZIP` 또는 `git clone`)합니다.
2. 폴더 내의 **`sconc.exe`** (또는 `run_sconc.bat`)를 더블클릭합니다.
3. 별도의 프로그램 설치 없이 즉시 **독립 데스크톱 앱 창**이 열리며 모든 기능을 사용할 수 있습니다.

### 방법 B: 소스코드 직접 빌드 및 전역 명령어(`sconc`) 등록 (개발자용 선택 사항)
소스코드를 직접 수정·컴파일하거나 터미널 어디서든 `sconc` 명령어로 실행하고 싶은 경우에만 아래 과정을 수행합니다 (Rust 툴체인 필요):
```cmd
install.bat
```

## 📖 말뭉치 데이터베이스 구축 방법

1. 상단 내비게이션의 **[📁 말뭉치 폴더 지정 DB 생성]** 탭을 클릭합니다.
2. **[📂 폴더 찾아보기...]** 버튼을 눌러 원본 말뭉치 파일들이 위치한 폴더를 선택하거나 경로를 입력합니다.
3. **[🚀 데이터베이스 생성 시작]** 버튼을 클릭하면 실시간 진행률(`%`)과 함께 데이터베이스(`.corpdb`)가 자동 구축됩니다.

```text
concordancer_sconc/
├── sconc.exe                # Windows 무설치 독립 실행 파일 (UI·PUA테이블·SQLite·DB빌더 올인원 내장)
├── assets/                  # 필수 폰트 및 데이터 파일
│   ├── data/
│   │   └── pua_table.json   # 한양 PUA ↔ 유니코드 첫가끝 매핑 테이블
│   └── fonts/
│       ├── HANBatang.ttf    # 옛한글 폴백 웹폰트 (함초롬바탕)
│       └── KoPubWorldDotumMedium.ttf # 기본 UI 폰트
├── engine/                  # Rust 고속 백엔드 코어 및 내장 DB 빌더
│   ├── Cargo.toml           # Rust 패키지 명세 (sconc v0.1)
│   └── src/
│       ├── main.rs          # HTTP 서버 라우터, 웹 자산 서빙, 독립 앱 런처, 단위 테스트
│       ├── models.rs        # AppState, MemoryProfile, API DTO 및 공통 유틸
│       ├── normalizer.rs    # 한양 PUA ↔ 유니코드 첫가끝 정규화, [초/중/종] 자소 매처
│       ├── search.rs        # 초고속 다층 검색, KWIC 문맥 확장, 3단계 검색단위, 스트리밍
│       ├── handlers.rs      # 문서 조회/삭제, 세그먼트 편집, DB 빌더 제어 API
│       ├── editor.rs        # 원문 4단계 라인 추적(Source Jump) 및 외부 에디터 연동
│       ├── builder.rs       # 11종 말뭉치 포맷 자동 판별 및 인코딩 감지 네이티브 DB 빌더
│       └── jamo_table.rs    # 대괄호 자소([초/중/종]) 분해용 원자 자모 테이블
├── web/                     # 반응형 프런트엔드 UI (sconc.exe 내부에 자동 임베딩됨)
│   ├── index.html           # 반응형 레이아웃 및 다중 탭 화면
│   ├── styles.css           # UI 스타일시트 및 KWIC 하이라이트
│   ├── app.js               # 실시간 스트리밍 검색, 다중 탭, Shift 다중 선택, DB 빌더 폴링
│   └── hangul_automata.js   # 한컴 두벌식 옛글 입력 오토마타
├── corpus_builder.py        # CLI 보조용 Python 말뭉치 DB 변환 스크립트
├── install.bat              # 개발자용 빌드 및 전역 명령어(sconc) 등록 스크립트
├── run_sconc.bat            # Windows 원클릭 실행 런처
└── README.md                # 사용 설명서
```
