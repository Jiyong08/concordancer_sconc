# sconc 다중 검색 방식 및 자소 [0/1/01] 복합 검색 사용자 가이드

본 문서는 **sconc (말뭉치 검색기 및 형태 분석기)**의 신규 다중 검색 체계, 새롭게 도입된 자소 슬롯 표기법(`0`, `1`, `01`), 그리고 형태소·형태의미·구문표지 층위에서의 자소 및 정규표현식 복합 검색 사용법을 상세히 기술합니다.

---

## 1. 개요 및 변경 핵심 요약

기존 sconc는 단일 드롭다운(`<select id="select-mode">`)을 통해 "표층", "자소", "형태소", "의미", "구문", "정규식" 중 하나만을 택일해야 했으며, 자소 검색 시 와일드카드(`*`, `?`, `+`)를 사용했습니다.

이번 12차 전면 개편을 통해 다음 기능이 완전히 새로 구현되었습니다:
1. **복합 검색 방식 체크박스 UI (`search-method-popup`)**:
   - **검색 대상 층위 (Targets)**: `원문 표층(surface)`, `형태소/품사(morph)`, `형태의미(sense)`, `구문표지(syntax)`를 원하는 대로 다중 체크.
   - **검색 연산 방식 (Methods)**: `기본 텍스트(음절/어절)`, `자소 검색([0/1/01])`, `정규표현식(Regex)`을 복합적으로 다중 체크.
2. **신규 자소 슬롯 표기법 (`0`, `1`, `01`)**:
   - `0`: 해당 자리에 자소가 **0개(없음)** (종성에 쓰면 **받침 없는 음절**만 매칭).
   - `1`: 해당 자리에 자소가 **임의의 1개** 존재 (종성에 쓰면 **받침 있는 음절**만 매칭).
   - `01`: 해당 자리에 자소가 **있거나 없거나(0개 또는 1개) 모두 검색**.
3. **다층 층위(형태소/품사, 형태의미, 구문표지)에서의 자소 및 정규표현식 매칭**:
   - 형태소 분석 필드(`morph_flat`)에서도 `[1/ㅏ/0]/VV`와 같은 자소 브래킷 검색 지원.
   - 형태소·형태의미·구문표지 필드에 대한 정규표현식(`Regex`) 검색 지원.
4. **자소 검색과 정규표현식의 동시 사용 (복합 질의)**:
   - 질의어 내의 자소 브래킷 `[초/중/종]`을 한글 음절 정규식 패턴으로 자동 변환(Transpile)하여, 정규식 메타문자(`.*`, `+`, `|`, `^`, `$`)와 자소 브래킷 문법을 한 쿼리에서 결합 사용 가능.

## 2. 자소 검색 새 문법 (`0`, `1`, `01`) 상세 안내

대괄호 안에 초성, 중성, 종성을 슬래시(`/`)로 구분하여 입력하며, 각 자리에 `0`, `1`, `01`을 지정합니다.

| 기호 / 표기 | 의미 및 규칙 | 검색식 예시 | 매칭 결과 예시 |
| :--- | :--- | :--- | :--- |
| **`0`** | 해당 자리에 자소가 **0개(없음)** | `[ㄱ/ㅏ/0]` | **가** ('각, 간, 갈' 등 받침 있는 음절 제외) |
| | | `[1/1/0]` | **받침 없는 모든 한글 음절** (가, 나, 다, 너, 보, 두…) |
| **`1`** | 해당 자리에 자소가 **임의의 1개** | `[ㄱ/ㅏ/1]` | **각, 간, 갇, 갈, 감, 갑, 갓, 강, 닭…** (받침 있는 음절) |
| | | `[1/ㅏ/0]` | **가, 나, 다, 라, 마, 바, 사…** (무받침 'ㅏ' 음절 전체) |
| | | `[1/1/1]` | **받침 있는 모든 한글 음절** (각, 눈, 달, 밥, 숲…) |
| **`01`** | 해당 자리에 자소가 **있거나 없거나(0개 또는 1개)** | `[ㄱ/ㅏ/01]` | **가, 각, 간, 갈, 감, 값…** ('가' 계열 전체 음절) |
| | | `[ㅎ/ㅏ/0][ㄴ/ㆍ/01]` | **하ᄂᆞ, 하ᄂᆞᆯ** |

> **하위 호환성 안내**: 기존의 와일드카드 문자(`*`, `+`, `?`)도 엔진 레벨에서 완벽하게 호환 작동합니다.

## 3. 다층 층위 및 복합 검색 연동 안내

### 3.1. 형태소/품사 층위 자소 검색
- **설정**: 검색 대상에서 `[x] 형태소/품사`, 검색 방식에서 `[x] 자소 검색` 체크.
- **검색식**: `[1/ㅏ/0]/VV`
  - 초성 1개, 중성 'ㅏ', 종성 0개인 어간을 가진 동사(`VV`)를 검색.
  - 매칭: `가/VV`, `사/VV`, `차/VV`, `타/VV` 등.
- **결과**: 형태소 필드에서 매칭된 해당 어절을 원문에서 탐색하여 원문 해당 위치를 정확히 하이라이트하며, 결과 레이블에 `형태소/자소`로 표시됩니다.

### 3.2. 형태의미 층위 복합 검색
- **설정**: 검색 대상에서 `[x] 형태의미`, 검색 방식에서 `[x] 정규표현식` 또는 `[x] 자소 검색` 체크.
- **검색식**: `__0[1-9]/NNG`
  - 의미 번호가 부착된 체언(`NNG`)을 정규표현식으로 정밀 검색.
- **결과**: 결과 레이블에 `형태의미/정규식`으로 표시됩니다.

### 3.3. 구문표지 층위 검색
- **설정**: 검색 대상에서 `[x] 구문표지` 체크.
- **검색식**: `\(NP_SBJ` 또는 `\(VP`
  - 주어 명사구(`NP_SBJ`) 또는 동사구(`VP`)를 포함한 구문 트리 탐색.
- **결과**: 결과 레이블에 `구문/정규식` 또는 `구문분석`으로 표시됩니다.

### 3.4. 자소 검색 + 정규표현식 복합 질의
- **설정**: 검색 방식에서 `[x] 자소 검색`과 `[x] 정규표현식`을 동시 체크.
- **검색식 예시**: `[ㄱ/ㅏ/0].*다/EF`
  - '가' 음절로 시작하여 종결어미 '다/EF'로 끝나는 문맥 패턴 검색.
  - 내부 자소 브래킷 `[ㄱ/ㅏ/0]`이 정규식 엔진에 적합한 패턴으로 자동 변환되어 한 번의 쿼리로 초고속 매칭됩니다.

## 4. 백엔드(Rust) 구현 명세

- **파일**: `engine/src/main.rs`
- **핵심 데이터 구조**:
  ```rust
  #[derive(Debug, Clone, PartialEq, Eq)]
  enum GlobOp {
      Zero,      // 0 : 0 atomic jamos (empty)
      One,       // 1 : 1 atomic jamo (any)
      ZeroOrOne, // 01: 0 or 1 atomic jamo
      Star,      // * : 0 or more atomic jamos
      Plus,      // + : 1 or more atomic jamos
      Question,  // ? : 1 atomic jamo
      Lit(char),
  }
  ```
- **매칭 루프 (`handle_search`)**:
  - `targets` 파라미터(`surface`, `morph`, `sense`, `syntax`) 및 `methods` 파라미터(`text`, `jamo`, `regex`) 수신.
  - 각 층위별로 선택된 방식(자소 토큰 분해, 정규식, 텍스트)을 순차 검사하고, 일치 시 어절 매핑을 통해 원문 하이라이트 구간(`start_c`, `end_c`)과 일치 레이블(`match_layer`) 생성.
- **단위 검증 (`cargo test`)**:
  - `test_jamo_0_1_01_syntax`: `[ㄱ/ㅏ/0]`, `[ㄱ/ㅏ/1]`, `[ㄱ/ㅏ/01]`, `[1/ㅏ/0]`, `[1/1/0]`, `[1/1/1]` 단위 테스트 100% 통과.
  - `test_morph_jamo_search`: 형태소 필드 `morph_flat` 대상 `[1/ㅏ/0]/VV` 자소 매칭 단위 테스트 100% 통과.
  - `test_expand_bracket_syntax_to_regex`: 자소+정규식 복합 쿼리 변환 테스트 100% 통과.
